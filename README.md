# ちぎりメモ

箇条書きの「書く」と、メモをカードにして並べる「ひろげる」を切り替えられるメモ帳です。

- 「書く」でメモを選び、元の文章と連動させてボードに置けます。完了した項目は一覧の下に移り、ボードのカードは小さくなります。
- 「ひろげる」でカードの余白をドラッグすると移動できます。選択枠の角でサイズを変え、丸いハンドルで回転できます。
- カードを線でつなぐ、ペンやマーカーで書く、紙や背景の色を変える、素材を貼るといった操作ができます。カードの上から書いた描画はカードについて動きます。固定用テープをカードに重ねると、その位置に留められます。

## GitHub Pagesを更新する

リポジトリのルートにある `index.html` を、このパッチの `index.html` で差し替えます。GitHubの **Add file → Upload files** からアップロードしてコミットできます。CSS・JavaScriptとデコ素材195点は `index.html` に同梱しています。

公開URLが同じなら、ブラウザに保存してあるメモを引き続き開けます。メモは使っているブラウザ内に保存されます。

## 手元で開く

`index.html` をブラウザで開いて試せます。素材の出典は [ASSETS.md](ASSETS.md) に記載しています。操作アイコンには [Lucide](https://lucide.dev/) を使用しています。
